# 使用文档

这份文档讲「怎么用」和「出问题怎么查」。安装步骤在 [README](../README.md)。

---

## 1. 两个界面

| 界面 | 位置 | 干什么 |
| --- | --- | --- |
| 悬浮面板 | 学习通页面右上角 | 显示实时日志（在播什么、答了几题、AI 在写什么），可拖动、可折叠、双击标题复制日志 |
| 扩展弹窗 | 浏览器工具栏图标 | 所有开关和配置：倍速、题库、AI 桥地址、诊断按钮 |

改弹窗里的设置会自动保存，页面上的逻辑 1 秒内生效，不用刷新。

---

## 2. 刷课

打开课程章节页（`mooc1.chaoxing.com/mooc-ans/mycourse/studentstudy?...`），扩展会自动：

1. 找到页面里时长最长的 `<video>` 并播放
2. 按弹窗里的倍速设置调速，按设置静音
3. 播放器弹出「视频弹题」时自动选一个答案并提交
4. 视频播完后点「下一节 / 下一章 / 下一个」

面板日志会写 `开始播放` / `已切到 2 倍速` / `点下一节` 之类的话。如果一直卡住不动，先看面板日志里有没有 `没找到视频`——那通常是整章是文档或测验，不是视频。

---

## 3. 答题与题库

进入章节测验 / 作业页（URL 含 `/work/`、`/exam/`、`dowork` 之类），扩展会自动：

1. 扫出所有题目，判断题型（单选 / 多选 / 判断 / 填空）
2. 依次在三个地方找答案：**你的本地文本题库 → 已积累的题库 → 你配置的答题 API**
3. 填进去；开了「自动提交」才会点提交，否则留给你自己核对

### 题库怎么长起来

每次你提交后，如果答案页显示了「正确答案：XXX」，扩展会把「题干 + 正确答案」收进本地题库。同一道题下次出现就直接秒填。弹窗里的「题库 N 条 · 答对 a/b（xx%）」就是这个积累量和历史正确率。

### 导入 / 导出

弹窗里「导出题库」会给你一个 JSON：

```json
{
  "version": 2,
  "bank": { "题目哈希": { "q": "题干", "a": "A", "t": 1700000000000 } },
  "localBank": "题目1|答案1\n题目2|答案2",
  "stats": { "right": 40, "wrong": 6 }
}
```

「导入题库」也认下面这些简单格式，方便你从别处搬：

```json
[{ "q": "数据库设计的第一步是什么", "a": "需求分析" }]
```

```json
{ "数据库设计的第一步是什么": "需求分析" }
```

或者纯文本，一行一题：`题目|答案`（多空答案用 `||` 分隔）。

> 题库存在本地扩展存储里，清浏览器数据会丢，建议定期导出备份。

## 4. AI 回复讨论

### 4.1 两种页面都支持

| 页面 | 地址样子 | 扩展怎么干 |
| --- | --- | --- |
| 课程学习页右栏 | `.../studentstudy?...` 右侧「讨论」标签 | 自动切到讨论面板，逐条读话题、生成、回复 |
| 独立话题页 | `groupweb.chaoxing.com/course/topic/v3/bbs/...` | 直接在当前页读话题和楼层，写进回复框 |

### 4.2 流程

1. 打开弹窗，确认「AI 桥」那行显示 **桥在线 · 模型名**（不是就去看第 6 节）
2. 勾上「自动回复讨论」，或在弹窗点「立刻回一条」
3. 扩展抓取话题标题 + 已有发言 → 交给模型 → 生成一句客观陈述
4. **弹出一张卡片**：「AI 拟好了一句，发吗？」可以改字、点「换一句」重新生成、按 Esc 放弃
5. 点「发送」才真正发出去；发完 1.5 秒自动关掉这个话题页（可在弹窗关掉这个行为）

### 4.3 统一回复：一个话题只留一条

如果你以前已经用这个扩展发过回复，再点「立刻回一条」时：

- 楼层的「删除」按钮只有你自己发的回复才有，扩展靠这个认出哪些是它发过的
- 有「编辑」入口 → 直接把旧楼层改成新说法（位置、楼层不变）
- 没有编辑入口 → 先删掉旧的，再在回复框发新的
- 删不掉（认不出确认按钮）→ **这次就不发**，免得页面上变成两条
- 旧回复也不会再被当成「同学的发言」喂给模型，避免新句子跟着老口气走

弹窗里的「清掉这页旧回复」可以把当前话题页上历史遗留的旧回复一次性清掉（最多 6 条）。

## 5. 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 自动播放 | 开 | 进入页面自动播视频 |
| 静音 | 开 | 强制静音，防止突然外放 |
| 倍速 | 2 | 1–16 倍 |
| 自动下一节 | 开 | 播完自动翻章 |
| 视频弹题自动答 | 开 | 弹题自动选一个 |
| 自动答题 | 开 | 测验页自动填答案 |
| 自动提交 | 关 | 建议先开着核对几次再打开 |
| 关闭自动补全猜测 | 关 | 开着则没答案的题留空，不乱猜 |
| 自动回收正确答案 | 开 | 提交后从答案页入库 |
| 自动回复讨论 | 关 | 开着才会无人值守发帖 |
| 每轮最多回 | 3 | 一次最多处理几个话题 |
| 回复字数 | 60 | 一句话长度上限 |
| 发送前先问我 | 开 | 关掉则直接发，不再弹卡片 |
| 回复完关掉这个话题页 | 开 | 发完自动关标签页 |
| AI 模式 | 桥 | 桥模式走本机 17310；直连模式扩展自己请求 |
| 桥地址 | `http://127.0.0.1:17310/summarize` | 改端口时同步改这里 |
| 自定义提示词 | 空 | 留空用内置的「客观概括、不用第一人称」规则 |

## 6. 故障排查

先看面板日志和弹窗里的 `#aiInfo`，再看「诊断当前页」的输出——它会打印地址、识别到的页面类型、输入框清单、可见按钮文字、抓到的标题和发言数。

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| `AI 没给答复：Failed to fetch` | 桥没起 | 双击 `bridge/启动AI桥.bat`，窗口别关；弹窗应显示「桥在线」 |
| `connect ECONNREFUSED 127.0.0.1:17310` | 同上，端口没监听 | `netstat -ano | findstr 17310` 确认 |
| 桥窗口报 401 / 403 | Key 和 baseURL 不配套 | 检查 `config.json` 的 `apiKey` 与 `baseURL` 是不是同一家 |
| 桥窗口报 404 model not found | 模型名不对 | 1.0.1 起会自动换，日志里看 `[自动换模型]`；还不行就换 Key 或换地址 |
| 提示「连不上 AI 桥」 | 桥没启动 | 双击 `bridge\启动AI桥.bat`，黑窗口要一直开着；没装 Node.js 会提示下载 |
| 不知道这个地址能用哪些模型 | — | 浏览器打开 `http://127.0.0.1:17310/models`，里面有清单 |
| 桥窗口报 not activated | 该模型没开通 | 换模型 |
| 日志里话题标题是「话题详情」「讨论区」 | 抓到面包屑了 | 用「诊断当前页」把按钮/标题清单发出来，补选择器 |
| 提示「没找到回复输入框」 | 页面结构变了 | 同上，诊断输出里看输入框清单 |
| 提示「那条旧回复删不掉」 | 确认弹窗按钮文案不认识 | 把弹窗截图或按钮文字发出来 |
| 点了发送但页面上没有 | 站点有前端校验 / 需要先展开回复区 | 先手动点一次「回复」看它是什么流程 |
| 表情、图片上传提示 | 站方限制 | 与本扩展无关 |

想重置某条话题的回复记录：弹窗里「清已回复记录」。

## 7. 自检清单

觉得不工作时，按顺序确认：

1. 扩展已「重新加载」，学习通页面已刷新（面板出现即注入成功）
2. 面板日志第一行是「已注入主框架：<当前地址>」
3. 弹窗显示「桥在线 · <模型名>」
4. 「诊断当前页」能打印出输入框和按钮
5. 再点「立刻回一条」，看日志走到哪一步停下

把 2–5 步的输出贴出来，基本能定位到具体是选择器、权限还是网络问题。
